# GoalX Hub Mobile

React Native app for Android and iOS. It opens on a splash screen, then sign in or registration, and talks to the GoalX Hub API at `/api/v1`.

## Run

1. Start the backend on port `8080`.
2. Install dependencies: `npm install`
3. Start the app: `npm start`
4. Android: `npm run android` (Android Studio emulator or a phone with Expo Go).
5. iOS: `npm run ios` on a Mac, or open the QR code in Expo Go on an iPhone.

Native `android` and `ios` projects are generated by Expo when you build. Do not edit those folders by hand. Cloud builds use the profiles in `eas.json`:

```bash
npx eas-cli@latest build --platform android --profile preview
npx eas-cli@latest build --platform ios --profile preview
```

iOS binaries are built on a Mac or with EAS. Expo Go is enough to try the app on an iPhone from Windows.

## Backend

The app calls:

- `POST /api/v1/auth/login` with `username` or `email`, and `password`
- `POST /api/v1/auth/register` with `email`, `password`, `fullName`, `role`, and `organizationId`
- `GET /api/v1/auth/me`
- `POST /api/v1/auth/refresh`
- `POST /api/v1/auth/logout`

The address is chosen automatically from the Metro host so a phone on the same network can reach the computer running Spring Boot. Set `EXPO_PUBLIC_API_BASE_URL` (see `.env.example`) when that guess is wrong. Android development builds allow HTTP so a local server works. Use HTTPS before a store release.

Public registration currently returns a refusal from the API until an administrator enables it. The register screen shows that message.
